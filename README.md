## 👋 About Me

### Full Stack Developer | MERN Stack | TypeScript

I build full stack web applications, with a current focus on e-commerce experiences. My projects include a React and TypeScript storefront and a Node.js API with MongoDB, payments, authentication, caching, and admin analytics.

## 🚀 Selected Work

- **[MERN E-Commerce Frontend](https://github.com/iyogisharma001/mern-ecommerce-frontend)** — Storefront built with React, TypeScript, Redux Toolkit, and Stripe, with product browsing and admin dashboard views.
- **[MERN E-Commerce Backend](https://github.com/iyogisharma001/mern-ecommerce-backend)** — REST API built with Node.js, Express, TypeScript, and MongoDB. Includes Stripe payments, Firebase Admin authentication, role-protected admin routes, analytics aggregations, and server-side caching.
