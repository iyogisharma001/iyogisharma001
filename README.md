## ⚡ Athletics meets Engineering

> **The same discipline wins on the track and in the terminal.**

A 400m race is decided by pacing, not the first hundred metres — the same way a hard problem is decided by structure, not the first idea. Arm wrestling and wrestling teach you to hold position under pressure and wait for the opening; debugging teaches exactly the same patience. Training for both has given me one habit that carries across: **show up daily, measure honestly, and improve one rep at a time.**
